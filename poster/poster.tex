%% ── 1. What is a Knowledge Graph ─────────────────────────────
\secheader{What is a Knowledge Graph?}

A \textbf{knowledge graph} (KG) is a structured network of real-world facts.
Each fact is stored as a simple triple: \textbf{(subject, relation, object)}.
Google, Siri, Netflix, and Wikipedia all rely on knowledge graphs behind the scenes.

%% ── 2. Predicting Missing Links ──────────────────────────────
\secheader{Predicting Missing Links}

KGs are always \textit{incomplete}: facts are missing.
\textbf{Link prediction} is the task of automatically completing the graph
by ranking all candidate answers for a given query.

\vspace{0.25cm}
\begin{center}
\begin{tikzpicture}[>=Stealth, font=\small]
  \node[
    draw=navy, line width=1pt, rounded corners=6pt,
    fill=iceblue, inner xsep=8pt, inner ysep=6pt,
    font=\small\bfseries
  ] (h) {Barack Obama};
  %
  \node[
    draw=amber, line width=2pt, rounded corners=6pt,
    fill=amberlt, minimum width=1.1cm, minimum height=0.9cm,
    font=\Large\bfseries\color{amber}, right=2.5cm of h
  ] (q) {?};
  %
  \draw[->, navy, line width=1.8pt]
    (h) -- node[above, font=\scriptsize\bfseries\color{navy}]{born\_in} (q);
  %
  \node[
    draw=forest!50, fill=forestlt, rounded corners=5pt,
    inner sep=8pt, align=left, anchor=west
  ] at ($(q.east)+(0.35cm,0)$) {%
    {\small\bfseries\color{forest} AI ranking:}\\[4pt]
    \textcolor{forest}{\bfseries 1.~Honolulu~\checkmark}\\[2pt]
    \small 2.~Chicago\\[2pt]
    \small 3.~Kansas City%
  };
\end{tikzpicture}
\end{center}

\vspace{0.2cm}
We measure quality with \textbf{MRR} (Mean Reciprocal Rank): if the right
answer ranks 1st the score is 1.0; if 2nd, it is 0.5; and so on.
Higher MRR means better predictions.

\colsep

%% ── 3. Teaching AI with Wrong Answers ────────────────────────
\secheader{Teaching AI with Wrong Answers}

Models learn by contrasting correct facts with \textit{fabricated wrong facts}
(negatives). The quality of these negatives determines how much the model learns
at each training step.

\vspace{0.3cm}
\noindent
\begin{minipage}[t]{11.8cm}
\begin{tikzpicture}
  \node[
    draw=black!25, fill=softgray, rounded corners=7pt,
    inner sep=11pt, text width=10.5cm, align=left
  ] {%
    {\small\bfseries\color{warmgray}\textsc{Random negatives} (standard)}\\[7pt]
    \quad Obama \textrightarrow\ born\_in \textrightarrow\
      \textit{Ice cream}\\[3pt]
    \quad Obama \textrightarrow\ born\_in \textrightarrow\
      \textit{Mt.\ Everest}\\[3pt]
    \quad Obama \textrightarrow\ born\_in \textrightarrow\
      \textit{Atlantic Ocean}\\[8pt]
    {\small\color{warmgray}\textit{Obviously wrong.
      The model stops improving after a few epochs.}}%
  };
\end{tikzpicture}
\end{minipage}%
\hfill%
\begin{minipage}[t]{11.8cm}
\begin{tikzpicture}
  \node[
    draw=amber, line width=1.5pt, fill=amberlt,
    rounded corners=7pt, inner sep=11pt,
    text width=10.5cm, align=left
  ] {%
    {\small\bfseries\color{amber}\textsc{Hard negatives} (our method)}\\[7pt]
    \quad Obama \textrightarrow\ born\_in \textrightarrow\
      \textit{Chicago}\\[3pt]
    \quad Obama \textrightarrow\ born\_in \textrightarrow\
      \textit{Kansas City}\\[3pt]
    \quad Obama \textrightarrow\ born\_in \textrightarrow\
      \textit{Honolulu}\textsuperscript{*}\\[8pt]
    {\small\color{amber!80!black}\textit{Plausible but wrong.
      The model keeps improving.}}%
  };
\end{tikzpicture}
\end{minipage}

\vspace{0.25cm}
{\small\textsuperscript{*}Honolulu \emph{is} the right answer here,
which makes it the hardest possible negative to distinguish.}

\vspace{0.25cm}
{\small
\textbf{Our two-stage pipeline:}%
\step{1}{Generate 64 random candidate wrong answers (Bernoulli corruption).}%
\step{2}{Select the 8 most informative ones using a \textbf{strategy}:
  \textbf{Random} (control), \textbf{Hard} (top-scoring by the model),
  or \textbf{Mixed} (blend of both). Zero extra compute.}%
}

%% ── Conclusions ──────────────────────────────────────────────
\secheader{Take-Aways}

\begin{itemize}\setlength{\itemsep}{7pt}
  \item \textbf{Smarter negatives, free upgrade:} the hard negative strategy
    requires no extra computation — only a smarter selection from the same pool.
  \item \textbf{You don't need 100\% hard:} Mixed 30\% (roughly 2 hard
    examples per 8) recovers 95\% of the accuracy gain with greater
    training stability.
  \item \textbf{Rare facts benefit most,} exactly where knowledge graph
    completion is hardest and most valuable in practice.
  \item \textbf{Next steps:} dynamically adjust the hard fraction during
    training; scale experiments to Wikidata-5M.
\end{itemize}
